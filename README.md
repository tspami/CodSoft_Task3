# CodSoft_Task3
Iris Flower Classification Dashboard

## Overview
The **Iris Dataset Classification Dashboard** is an interactive Power BI dashboard designed to visualize and analyze the classification of Iris flowers into three species: **Setosa, Versicolor, and Virginica**. This dashboard provides insightful visual representations of sepal and petal measurements, model predictions, and classification performance.

## Dataset Description
The dataset consists of 150 observations of Iris flowers, categorized into three species:
- **Setosa**
- **Versicolor**
- **Virginica**

Each flower has the following four measurements:
- **Sepal Length** (cm)
- **Sepal Width** (cm)
- **Petal Length** (cm)
- **Petal Width** (cm)

## Dashboard Features
### 1. **Data Overview**
- Summary of dataset distribution with key statistics
- Bar charts representing species-wise count

### 2. **Feature Analysis**
- Scatter plots showing relationships between sepal and petal measurements
- Box plots displaying the distribution of measurements across species

### 3. **Machine Learning Model Predictions**
- Confusion matrix to show model accuracy
- Performance metrics including precision, recall, and F1-score
- Feature importance visualization

### 4. **Interactive Filters & Insights**
- Ability to filter data by species and measurement ranges
- Dynamic insights into classification trends

## How to Use the Dashboard
1. **Explore the dataset** using the summary statistics and charts.
2. **Analyze relationships** between different features using scatter plots and box plots.
3. **Evaluate model predictions** through the confusion matrix and performance metrics.
4. **Use filters** to focus on specific species or measurement ranges.
5. **Gain insights** into feature importance for species classification.

## Model Training Process (Behind the Dashboard)
1. **Data Preprocessing:** Handling missing values, normalizing features.
2. **Model Selection:** Training a classification model (e.g., Decision Tree, Random Forest, or SVM).
3. **Evaluation:** Assessing accuracy, precision, recall, and F1-score.
4. **Deployment in Power BI:** Importing results and integrating visuals.

## Conclusion
This Power BI dashboard provides a comprehensive visualization of the Iris dataset classification, offering both exploratory data analysis and machine learning insights. It serves as a valuable tool for understanding species differentiation based on sepal and petal measurements.
